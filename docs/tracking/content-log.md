# Innehållsgranskning

Löpande feedback på lärstigar, scenarion och teoriinnehåll i `apps/app/content/`.
Hanteras **separat** från buglog.md (kodbuggar) och todo.md (programfunktionalitet).

Registrera feedback här när du testar innehållet — oavsett om det är en formuleringsdetalj,
en pedagogisk brist eller ett felaktigt scenario-värde.

---

## Format

```
### [filnamn] — Kort beskrivning
**Datum:** ÅÅÅÅ-MM-DD
**Fil:** content/[relativ sökväg]
**Feedback:**
Detaljerad beskrivning av vad som behöver förbättras.
**Status:** Noterad | Pågår | Klar
```
