# PID-simulator App (Huvudversion)

Denna är huvudversionen av PID-simulator - en webbaserad, helt offline-fungerande applikation avsedd för skoldatorer och enkla distributioner.

## Körning
1. Öppna `index.html` direkt i webblasaren (dubbelklick).
2. Ingen installation behövs.
3. Ingen internetanslutning behövs.

## Egenskaper
- Ingen fetch
- Ingen extern import
- Ingen server
- All data är inbyggd i app.js
