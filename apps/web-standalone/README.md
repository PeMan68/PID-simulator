# Web Standalone

Denna variant ar avsedd for skoldatorer utan adminrattigheter och utan lokal server.

## Korning
1. Oppna `index.html` direkt i webblasaren (dubbelklick).
2. Ingen installation behovs.
3. Ingen internetanslutning behovs.

## Egenskaper
- Ingen fetch
- Ingen extern import
- Ingen server
- All data ar inbyggd i app.js
